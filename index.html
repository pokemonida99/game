HOW IT'S MADE

這些遊戲怎麼做的

不是用遊戲引擎拉出來的，是用中文跟 AI 討論、一版一版改出來的。

說想法

用中文跟 Claude Code 描述玩法、角色和關卡，它寫程式、自己開瀏覽器測試、修 bug。

畫美術

GPT 依角色設定畫逐格動作圖、背景和卡面，再用程式自動去背、切格、對齊腳底。

配樂與演出

配樂、音效大多是 WebAudio 即時合成的原創曲；柏青哥的演出影片用 MiniMax H3 生成。

上線分享

推上 GitHub Pages，網址傳出去就能玩。鍵盤、手把、手機觸控都支援。
